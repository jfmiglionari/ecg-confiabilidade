# 0001 · Escopo: avaliação científica, não ferramenta clínica

- **Status:** aceita
- **Data:** 2026-11-17

## Contexto
Classificadores de ECG podem ser lidos como produto de diagnóstico. O valor desta pesquisa está em medir quando eles são confiáveis, não em entregar um sistema para uso clínico.

## Decisão
O projeto avalia cientificamente o desempenho, a calibração e a incerteza de classificadores entre bases. Nenhum artefato é proposto para diagnóstico.

## Consequências
Métricas de confiabilidade (calibração, risco-cobertura) têm o mesmo peso das de acerto. Não há validação clínica nem interface para usuário final.
